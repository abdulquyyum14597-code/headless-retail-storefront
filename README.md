# Headless E-Commerce & Retail Storefront

A high-performance, server-rendered e-commerce web application built with **React, Next.js App Router, Tailwind CSS, and Wix Headless SDK**. Designed for optimized performance, server actions, dynamic product catalog management, and seamless cart/checkout workflows.

## 🚀 Core Features
- **Modern Stack:** Built using Next.js Server Components and Server Actions for lightning-fast server-side rendering and minimal client-side JavaScript overhead.
- **Wix Headless Integration:** Integrates securely with Wix e-commerce backends to manage inventory, catalog fetching, and customer sessions.
- **Responsive UI/UX:** Styled using Tailwind CSS with modular component architecture, custom cart modals, and dynamic product grids.

## 📂 Project Structure
- `src/app/` — Next.js App Router pages, layouts, and API routing.
- `src/components/` — Modular UI building blocks (Navbar, Cart, Product Cards, Footers).
- `src/lib/` — Wix SDK configuration and client helper instances.
